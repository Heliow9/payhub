# PayHub 0.4.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a 0.4.1 com dados Sage vigentes, telefone BR, sincronização cadastral, PWA discriminativo, assinatura desenhada visível no administrativo e PDF assinado sem truncamento.

**Architecture:** O conector .NET 3.1 passa a selecionar históricos por vigência e enriquecer o snapshot. API mantém o snapshot e expõe sincronização/evidência com autorização existente. Dashboard compartilha um componente discriminativo de holerite entre administrativo e PWA. O PDF assinado ganha bloco horizontal próprio para a evidência textual.

**Tech Stack:** .NET 8, Node.js 22, TypeScript, Express, MySQL, React/Vite.

**Spec:** `docs/superpowers/specs/2026-09-17-payhub-0.4.1-sage-signature-pwa-design.md`

- Empresa Sage permanece código 1.
